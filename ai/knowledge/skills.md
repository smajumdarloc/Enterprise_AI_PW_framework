# AI Test Automation Skills

## UI Automation

The framework can:

- Navigate to application pages.
- Locate UI elements.
- Click buttons.
- Enter text.
- Validate visible elements.
- Validate text.
- Add products to the cart.
- Navigate through supported checkout flows.

## Test Generation

The AI can:

- Analyze requirements.
- Generate positive test cases.
- Generate negative test cases.
- Generate boundary test cases.
- Assign test case priority.
- Generate preconditions.
- Generate test steps.
- Generate expected results.

## Test Validation

The framework can:

- Validate AI output using Zod.
- Validate test case capabilities.
- Reject unsupported scenarios.
- Skip unsupported test cases.
- Execute supported test cases.
- Record execution results.

## Reporting

The framework can:

- Record passed test cases.
- Record failed test cases.
- Record skipped test cases.
- Record reasons for skipped tests.
- Generate AI execution reports.

## AI Failure Analysis

The framework can:

- Capture Playwright failures.
- Inspect page information.
- Extract failed locators.
- Suggest alternative locators.
- Request AI-based failure analysis.

## Limitations

The framework cannot currently:

- Modify backend application data.
- Modify database records.
- Create arbitrary application state.
- Execute unsupported Playwright actions.
- Automatically create new Page Objects.
- Automatically modify framework source code.
